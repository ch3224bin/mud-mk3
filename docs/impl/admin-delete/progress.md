## 창호 확인 항목

스펙 `## 관리 툴 삭제 (admin-delete)` 의 `(제안)` 으로 남은 것이다. 결정 자체는 고나 판단(창호 위임)이고 아래 세부를 창호가 확인한다.

- 접속 중 판정은 계정으로 열린 게임 연결이 있으면 접속 중이다(영근 고르는 중 포함). **관리자가 접속 중인 플레이어 연결을 끊는 기능은 없다** — 플레이어가 `종료` 하거나 창을 닫을 때까지 기다린다.
- 삭제 로그 형식: 지우기가 커밋된 뒤 `info` 한 줄(몹·캐릭터 각각), 거절은 남기지 않음, DB 감사 표 없음.
- 확인 문구: 몹(배치 있을 때 `…배치 N곳도 함께 지워지고, 세계에 나와 있는 …은/는 사라집니다.`, 배치 수는 화면을 연 때 값), 캐릭터 이름 입력 칸(글자 그대로, 공백 자르지 않음)·안내 문구·`취소`.
- 지운 뒤 화면: 몹은 `/mobs/`, 캐릭터는 `/characters/` 로 이동. 실패하면 칸을 연 채 서버 `detail`.
- 몹이 세계에서 사라지는 때: 삭제 직후가 아니라 다음 서버 틱(1초 안). 교전 중이던 플레이어는 알림 없이 교전에서 빠지고, 지운 뒤 다음 틱 전에 쓰러지면 드롭 없는 시체.
- 캐릭터를 지운 뒤 그 계정은 다음 접속 때 이름 prompt 부터 다시 시작하고, 지운 이름은 바로 다시 쓸 수 있다.
- 브라우저에서 직접 확인할 것: 몹 삭제 확인 문구(배치 0·N곳, 조사 `은`/`는`), 캐릭터 이름 입력 삭제 확인(이름이 같을 때만 `삭제` 켜짐, 접속 중 409 문구).
