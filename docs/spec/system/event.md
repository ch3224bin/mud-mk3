# 이벤트 · 시나리오

정해진 시나리오를 진행하는 상황. → [목차](index.md)

## 이벤트 · 시나리오

- 이벤트 같은 특정 시나리오를 진행하는 상황을 다룰 수 있어야 한다.
- 이벤트는 관리 툴에서 입력한다. 하드 코딩은 최대한 피하되, 어쩔 수 없는 경우도 있다. → [관리 툴](admin-tool.md#데이터-주도-콘텐츠)

## 첫 접속 튜토리얼

- 게임에 처음 접속하면 특정 이벤트를 거쳐 튜토리얼을 진행하고, 정해진 시작 마을로 간다.
- 튜토리얼 단계·내용은 룰북을 따른다. → [룰북: 입문 · 튜토리얼](../game-rule/character.md#튜토리얼), [용어집: 튜토리얼 이벤트](../glossary.md)
- 이벤트·시나리오 시스템의 첫 사용처다.

## 열린 질문

- 시나리오를 관리 툴에서 어떤 형태로 만드는가? (단계 목록, 조건-행동 규칙, 스크립트 등)
- 시나리오 진행 중에는 어떤 명령이 막히거나 바뀌는가? (예: 튜토리얼 중 이동 범위 제한)
- 시나리오는 혼자 진행하는 것만 있는가, 여러 플레이어가 함께 겪는 것도 있는가?
- 퀘스트·비경 안 스토리라인과 이벤트·시나리오 시스템은 같은 틀을 쓰는가? → [퀘스트 · 공적 교환](quest.md), [월드 구조](world-structure.md)
