# 월드 구조

월드·존·인스턴스(비경). → [목차](index.md)

존은 룰북의 [지역](../game-rule/world.md#지역)과 같은 것이다. 이 문서에서는 '존(지역)' 으로 쓴다.

게임 규칙(방이 가지는 것, 출구, 이동, 전송진, 게임 시간)은 [룰북: 세계와 이동](../game-rule/world.md), 비경 규칙은 [룰북: 비경 탐사](../game-rule/game-structure.md#비경-탐사)를 따른다.

## 계층

| 단위 | 설명 | 룰북 용어 |
|---|---|---|
| 월드 | 게임 세계 전체. 하나만 운영한다. → [플랫폼](platform.md#단일-월드) | — |
| 존 | 월드를 나누는 단위. 방들을 묶는다 | [지역](../game-rule/world.md#지역) (같은 것) |
| 인스턴스 | 비경 | [비경](../game-rule/game-structure.md#비경-탐사) |

- 존(지역)·인스턴스를 이루는 가장 작은 단위는 룰북의 [장소(방)](../game-rule/world.md#장소)다.
- 맵(존(지역)·방·출구)과 비경은 관리 툴에서 만든다. → [관리 툴](admin-tool.md)
- 1차 이터레이션: 관리 툴에서 맵(방·출구)을 만들고 게임에서 돌아다니기까지. → [이터레이션 계획](index.md#이터레이션-계획)
