# 월드 구조

월드·존·인스턴스(비경). → [목차](index.md)

게임 규칙(방이 가지는 것, 출구, 이동, 전송진, 게임 시간)은 [룰북: 세계와 이동](../game-rule/world.md), 비경 규칙은 [룰북: 비경 탐사](../game-rule/game-structure.md#비경-탐사)를 따른다.

## 계층

| 단위 | 설명 | 룰북 용어 |
|---|---|---|
| 월드 | 게임 세계 전체. 하나만 운영한다. → [플랫폼](platform.md#단일-월드) | — |
| 존 | 월드를 나누는 단위 | [지역](../game-rule/world.md#지역)으로 보임 (확인 필요 → 열린 질문) |
| 인스턴스 | 비경 | [비경](../game-rule/game-structure.md#비경-탐사) |

- 존·인스턴스를 이루는 가장 작은 단위는 룰북의 [장소(방)](../game-rule/world.md#장소)다.
- 맵(존·방·출구)은 관리 툴에서 만든다. → [관리 툴](admin-tool.md)

## 열린 질문

- 존은 룰북의 지역과 같은 것인가? (룰북의 지역: 방들을 묶는 큰 단위, 지역마다 분위기·난이도가 다름)
- 인스턴스(비경)는 들어갈 때마다 새로 만들어지는 사본인가? 혼자 들어가는 비경과 여럿이 들어가는 비경은 사본을 어떻게 나누는가? → [룰북: 비경 탐사](../game-rule/game-structure.md#비경-탐사)
- 성·종문·동부는 월드 구조에서 어떤 단위인가? (존 안의 방 묶음인가, 따로인가) → [룰북: 게임 구성](../game-rule/game-structure.md)
