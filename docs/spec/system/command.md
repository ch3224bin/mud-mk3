### 대화형 명령어

- 플레이어끼리 말을 주고받는 명령(말하기, 귓속말, 외치기). [멀티 유저](platform.md#멀티-유저)에서 쓰인다.
- NPC와의 대화는 `대화 <NPC> [낱말]` 이다. `말` 이라는 명령은 없다. → [2차 명령어](#2차-명령어), [NPC](npc.md)

## 1차 명령어

1차에 있는 명령이다. 명령어는 정해진 이름·줄임말로만 알아듣고 앞부분 일치는 받지 않는다(룰북 입력 문법과 같다). 입력은 최대 500자고, 넘으면 `명령이 너무 깁니다.`(룰북에 아직 없음)를 보낸다. (제안) → [룰북: 명령어](../game-rule/commands.md), [룰북: 이동 · 보기](../game-rule/commands.md#이동--보기), [룰북: 말하기 · 계정](../game-rule/commands.md#말하기--계정)

| 입력 | 하는 일 | 출력 |
|---|---|---|
| `보기`, `ㅂ` | 지금 방 다시 보기 | `room`(`zoneEntered=false`) |
| `보기 <무엇이든>` | 1차엔 자세히 보기가 없다 | `system/info` `아직 자세히 볼 수 없습니다.`(룰북에 아직 없음) |
| `동` `서` `남` `북` `북동` `북서` `남동` `남서` `위` `아래`, `e` `w` `s` `n` `ne` `nw` `se` `sw` `u` `d`(대소문자 무시) | 그 방위 출구로 이동 | 성공: 새 방 `room`. 실패: `system/error` `그쪽으로는 길이 없습니다.` |
| `말하기 <내용>`, `'<내용>`(띄어 쓰지 않아도 됨) | 같은 방 모두에게 | 나: `say(self=true)` `한백: "길을 묻겠소."`, 남: `say(self=false)` `한백이 말한다: "길을 묻겠소."`. 내용 없음: `system/error` `무엇이라 말하시겠습니까?`. 200자 넘음: `system/error` `말은 200자 이내로 하십시오.`(룰북에 아직 없음) |
| `누구` | 접속한 사람과 있는 지역 | `system/info` 여러 줄: `접속한 사람 (2)` 다음 줄마다 `  한립    청석숲`(두 칸 들여쓰기, 이름 뒤 네 칸) |
| `도움말` | 명령 목록 (2차에 `대화` 추가) | `system/info` `명령: 보기(ㅂ) · 동 서 남 북 북동 북서 남동 남서 위 아래 (e w s n ne nw se sw u d) · 말하기(') · 대화 <NPC> [낱말] · 누구 · 도움말 · 종료` |
| `종료` | 접속을 끊는다 | `system/info` `다음에 또 뵙겠습니다.` 뒤 닫기 1000 |
| 빈 줄 | 무시 | 없음 |
| 그 밖 | — | `system/error` `무슨 말인지 모르겠습니다. ('도움말' 로 명령을 볼 수 있습니다)` |

- 위 표 전체가 (제안)이다. 문구는 룰북 `commands.md` 를 따랐고, 룰북에 없는 문구는 위에 "룰북에 아직 없음" 으로 적었다.
- `말` 은 1차에 알 수 없는 명령으로 처리한다. NPC에게 말 걸기는 2차의 `대화` 다. → [2차 명령어](#2차-명령어)
- 출력 메시지 종류와 닫기 코드는 [플랫폼: 1차 WebSocket 메시지](platform.md#1차-websocket-메시지)를 따른다.

### 같은 방 알림 문구

룰북 출력 문체(묘사는 "~다")를 따른다. 조사 `이/가` 는 이름 끝 글자의 받침으로 고른다. 문구는 룰북에 아직 없다. (제안)

- 내가 북쪽으로 떠날 때 원래 방 사람들: `한백이 북쪽으로 떠난다.`(`위로`, `아래로`. 8방위는 `동쪽으로`·`북동쪽으로` 식) (제안)
- 도착한 방 사람들: `한백이 남쪽에서 다가온다.`(도착 방향은 이동 방향의 반대. `위에서`, `아래에서`) (제안)
- 접속해 세계에 들어옴: `한백이 나타난다.` 접속 끊김: `한백이 사라진다.` (제안)
- 다른 지역의 방에 들어가면 `room.zoneEntered=true` 이고 클라이언트가 방 위에 `◇ 청석숲` 한 줄을 그린다. 룰북 `◇ 지역 (권장: …)` 의 권장 경지는 1차에 없다. 접속 직후 첫 방도 `zoneEntered=true` 다. (제안)

### 캐릭터 생성 (1차 최소)

룰북 생성 절차에서 이름과 확인만 한다. 성별·외모·출신·영근은 다음 이터레이션이다. → [룰북: 캐릭터 생성](../game-rule/character.md#캐릭터-생성) (제안)

- 캐릭터가 없는 계정으로 접속하면 `session(creating)` 과 `prompt` `이름을 정하십시오. (한글 2~6자)`.
- 이름 규칙은 한글 2~6자(`^[가-힣]{2,6}$`)다. 어기면 `system/error` `이름은 띄어쓰기 없이 한글 2~6자로 정하십시오.` 뒤 같은 prompt. 이미 있으면 `system/error` `이미 있는 이름입니다. 다른 이름을 정하십시오.` 뒤 같은 prompt.
- 맞으면 `prompt` `이름 한백` 과 `이대로 만들려면 '확인', 고치려면 '뒤로'.`(두 줄). `확인` 은 만들고, `뒤로` 는 이름 prompt로 돌아가고, 그 밖은 같은 확인 prompt를 다시 보낸다.
- 만들면 `system/info` `캐릭터를 만들었습니다.`, `session(playing, 한백)`, 시작 방 `room` 을 보내고 시작 방 사람들에게 `appear` 알림을 보낸다.
- 계정당 캐릭터 1개(DB 유니크)다. 2차부터 NPC 이름 검사를 한다: 이름이 NPC 이름과 같아도 `이미 있는 이름입니다. 다른 이름을 정하십시오.` 다. 금지어 검사는 아직 없고 나중 이터레이션에서 한다. → [NPC: 2차 데이터 모델](npc.md#2차-데이터-모델) (제안)
- 위 prompt·system 문구는 룰북에 아직 없다.

## 2차 명령어

2차에 더하는 명령이다. 창호가 정했다(2026-11-14). → [이터레이션 계획: 2차 범위](index.md#2차-범위-npc-배치--기본-대화--성종문-정의)

| 입력 | 하는 일 |
|---|---|
| `대화 <NPC>` | 같은 방의 NPC에게 말을 건다. NPC가 인사말과 물어볼 수 있는 낱말(`[ ]`)을 보인다 |
| `대화 <NPC> <낱말>` | 그 낱말에 대해 묻는다. 모르는 낱말이면 그 NPC의 기본 대답이 나온다 |

- 낱말 묻기 규칙은 [룰북: 말 걸기](../game-rule/npc.md#말-걸기)를 따른다. 대사(인사말, 낱말마다 대답, 기본 대답)는 관리 툴에서 입력한다. → [NPC: 고유 대사](npc.md#고유-대사)
- 1차의 `말하기`(줄임 `'`)는 그대로 같은 방 플레이어에게 말하는 채팅이다.
- 조건으로 열리는 낱말과 NPC가 알아서 말하기는 2차에 없다. NPC는 플레이어가 `대화` 를 쓸 때만 답한다.
- 출력 문구, NPC 이름 줄여 부르기, 같은 방 다른 플레이어에게 보이는지는 2차 구현에서 아래와 같이 정했다. → [2차 이터레이션 열린 질문](index.md#2차-이터레이션-열린-질문) (제안)

### `대화` 해석과 출력

아래 전체가 (제안)이다.

- 해석: 첫 낱말이 `대화` 면 다음 낱말이 NPC, 그 뒤 나머지 전부가 낱말이다. 낱말의 앞뒤 `[` `]` 는 뗀다(`대화 왕씨 [단약]` = `대화 왕씨 단약`). 떼고 나서 빈 낱말(`대화 왕씨 []`)은 낱말이 없는 것으로 보아 인사말을 낸다. 줄임말은 없다. `말` 은 1차처럼 알 수 없는 명령이다. (제안)
- 대상 찾기: 같은 방에 배치된 NPC 가운데서만 찾는다(플레이어는 대상이 아니다). 이름 전체가 같은 NPC를 먼저, 없으면 이름이 입력으로 시작하는 NPC 가운데 방 보기 순서(만든 순서) 첫째를 고른다. 영문은 대소문자를 가리지 않는다. 번호(`2.왕씨`)는 2차에 없다. (제안)
- 낱말 찾기: 저장된 낱말과 글자 그대로 같을 때만 맞는다(영문 대소문자 무시). 앞부분 일치는 하지 않는다(룰북: 앞부분 일치는 대상·물건 이름에만). 맞는 낱말이 없으면 기본 대답이다. (제안)
- 공개 범위: NPC의 대답은 **묻는 플레이어에게만** 간다. 같은 방 다른 사람은 보지 않는다. 메시지는 `talk` 다. → [플랫폼: 2차 WebSocket 메시지 변경](platform.md#2차-websocket-메시지-변경) (제안)
- LLM 대화를 켠 NPC도 같은 정해진 대사로 답한다. → [NPC: 캐릭터 챗](npc.md#캐릭터-챗) (제안)
- `보기 <NPC>` 는 1차 그대로 `아직 자세히 볼 수 없습니다.` 다. (제안)

| 입력 | 출력 |
|---|---|
| `대화 왕씨` | `talk` `왕씨: "어서 오시오."`(룰북 예시 `왕씨가 주판을 튕기며 말한다. "…"` 의 서술형과 다르다. 2차는 `이름: "인사말"` 모양만 쓴다) 그리고 낱말이 있으면 다음 줄에 `물어볼 수 있는 낱말: [단약] [일거리]`(룰북에 아직 없음. 입력 순서, 낱말마다 `[ ]`, 사이 공백 하나). 낱말이 없는 NPC면 첫 줄만 |
| `대화 왕씨 일거리` | `talk` `왕씨: "<그 낱말의 대답>"` |
| `대화 왕씨 <모르는 낱말>` | `talk` `왕씨: "<기본 대답>"` |
| `대화` | `system/error` `누구에게 말을 거시겠습니까?`(룰북에 아직 없음) |
| 같은 방에 맞는 NPC가 없음 | `system/error` `여기에 그런 상대는 없습니다.`(룰북에 아직 없음) |

- `도움말` 문구는 2차에 `대화` 를 더해 `명령: 보기(ㅂ) · 동 서 남 북 북동 북서 남동 남서 위 아래 (e w s n ne nw se sw u d) · 말하기(') · 대화 <NPC> [낱말] · 누구 · 도움말 · 종료` 다. (제안)
- play-client 자동완성 명령 목록에 `대화` 가 `말하기` 다음에 있다. 이름 후보는 마지막 방 보기의 사람과 NPC 전부다. (제안)

## 3차 명령어

3차(아이템)에 더하는 명령이다. 창호가 정했다(2026-11-14). 명령 이름과 입력 형태는 룰북을 그대로 따른다. 출력 문구·이름 찾기·같은 방 알림 같은 세부는 3차 구현 때 정해 `(제안)` 으로 옮긴다. → [이터레이션 계획: 3차 범위](index.md#3차-범위-아이템--영석--상점--저물대귀속--주기)

| 입력 (룰북 그대로) | 하는 일 | 룰북 |
|---|---|---|
| `줍기 <물건> [수량]` | 같은 방 바닥의 물건을 줍는다 | [물건](../game-rule/commands.md#물건), [줍기와 버리기](../game-rule/item.md#줍기와-버리기) |
| `버리기 <물건> [수량]` (영석은 `버리기 하품 10`) | 바닥에 버린다 | [물건](../game-rule/commands.md#물건), [줍기와 버리기](../game-rule/item.md#줍기와-버리기) |
| `소지품` (`ㅈ`) | 칸·영석·물건 목록을 본다 | [정보](../game-rule/commands.md#정보), [저물대 · 저물탁](../game-rule/item.md#저물대--저물탁) |
| `보기 <물건>` | 물건의 이름과 설명을 본다 | [이동 · 보기](../game-rule/commands.md#이동--보기), [방 보기](../game-rule/world.md#방-보기) |
| `목록` | 상점 NPC가 파는 물건·값과 사 주는 종류를 본다 | [NPC · 상점 · 거래](../game-rule/commands.md#npc--상점--거래), [역할별 이용](../game-rule/npc.md#역할별-이용) |
| `사기 <물건> [수량]` | 상점에서 산다 | [상점에서 사고팔기](../game-rule/item.md#상점에서-사고팔기) |
| `팔기 <물건> [수량]` | 상점에 판다 | [상점에서 사고팔기](../game-rule/item.md#상점에서-사고팔기) |
| `주기 <대상> <물건> [수량]` (영석은 `주기 한립 하품 100`) | 같은 방 플레이어에게 바로 넘긴다 | [직접 거래](../game-rule/item.md#직접-거래) |
| `귀속 <물건>` / `귀속 해제 <물건>` | 물건을 귀속한다 / 푼다 | [물건](../game-rule/commands.md#물건), [귀속](../game-rule/item.md#귀속) |

- 상점 명령은 같은 방에 상점 NPC가 둘 이상이면 `<명령> <NPC> …` 로 지정한다(룰북). → [역할별 이용](../game-rule/npc.md#역할별-이용)
- `보기 <물건>` 은 2차까지 `아직 자세히 볼 수 없습니다.` 였다. 3차 범위의 `보기 <대상>` 은 물건 보기다. 사람·NPC를 자세히 보는 것은 창호가 정한 3차 범위에 없다.
- `값 <물건>`, 결제의 `확인`(상위 등급 영석 깨기)을 3차에 넣는지는 구현 때 정한다. → [3차 이터레이션 열린 질문](index.md#3차-이터레이션-열린-질문)
- 3차에 넣지 않는 명령: `복용`·`부적`·`진법`·`꺼내기`·`거두기`(아이템 효과), `교환`, `거래소 …`·`경매 …`·`찾기`, `수습`·`줍기 유품`(몹·사망이 없음), `제작`.
- 전투·기절이 아직 없으므로 룰북의 '전투 중에는 쓸 수 없음' 같은 상태별 막힘은 3차에 생기지 않는다. → [룰북: 상태별로 쓸 수 없는 명령](../game-rule/commands.md#상태별로-쓸-수-없는-명령)
- `도움말` 문구와 play-client 자동완성 목록에 3차 명령을 더한다. 문구는 구현 때 정한다. (제안)
