### 대화형 명령어

- 플레이어끼리 말을 주고받는 명령(말, 귓속말, 외치기). [멀티 유저](platform.md#멀티-유저)에서 쓰인다.
- NPC와의 대화는 [NPC](npc.md)에서 다룬다.

## 1차 명령어

1차에 있는 명령이다. 명령어는 정해진 이름·줄임말로만 알아듣고 앞부분 일치는 받지 않는다(룰북 입력 문법과 같다). 입력은 최대 500자고, 넘으면 `명령이 너무 깁니다.`(룰북에 아직 없음)를 보낸다. (제안) → [룰북: 명령어](../game-rule/commands.md), [룰북: 이동 · 보기](../game-rule/commands.md#이동--보기), [룰북: 말하기 · 계정](../game-rule/commands.md#말하기--계정)

| 입력 | 하는 일 | 출력 |
|---|---|---|
| `보기`, `ㅂ` | 지금 방 다시 보기 | `room`(`zoneEntered=false`) |
| `보기 <무엇이든>` | 1차엔 자세히 보기가 없다 | `system/info` `아직 자세히 볼 수 없습니다.`(룰북에 아직 없음) |
| `동` `서` `남` `북` `북동` `북서` `남동` `남서` `위` `아래`, `e` `w` `s` `n` `ne` `nw` `se` `sw` `u` `d`(대소문자 무시) | 그 방위 출구로 이동 | 성공: 새 방 `room`. 실패: `system/error` `그쪽으로는 길이 없습니다.` |
| `말하기 <내용>`, `'<내용>`(띄어 쓰지 않아도 됨) | 같은 방 모두에게 | 나: `say(self=true)` `한백: "길을 묻겠소."`, 남: `say(self=false)` `한백이 말한다: "길을 묻겠소."`. 내용 없음: `system/error` `무엇이라 말하시겠습니까?`. 200자 넘음: `system/error` `말은 200자 이내로 하십시오.`(룰북에 아직 없음) |
| `누구` | 접속한 사람과 있는 지역 | `system/info` 여러 줄: `접속한 사람 (2)` 다음 줄마다 `  한립    청석숲`(두 칸 들여쓰기, 이름 뒤 네 칸) |
| `도움말` | 1차 명령 목록 | `system/info` `명령: 보기(ㅂ) · 동 서 남 북 북동 북서 남동 남서 위 아래 (e w s n ne nw se sw u d) · 말하기(') · 누구 · 도움말 · 종료` |
| `종료` | 접속을 끊는다 | `system/info` `다음에 또 뵙겠습니다.` 뒤 닫기 1000 |
| 빈 줄 | 무시 | 없음 |
| 그 밖 | — | `system/error` `무슨 말인지 모르겠습니다. ('도움말' 로 명령을 볼 수 있습니다)` |

- 위 표 전체가 (제안)이다. 문구는 룰북 `commands.md` 를 따랐고, 룰북에 없는 문구는 위에 "룰북에 아직 없음" 으로 적었다.
- 룰북에서 `말` 은 NPC에게 말 걸기라 1차에는 알 수 없는 명령으로 처리한다. (제안)
- 출력 메시지 종류와 닫기 코드는 [플랫폼: 1차 WebSocket 메시지](platform.md#1차-websocket-메시지)를 따른다.

### 같은 방 알림 문구

룰북 출력 문체(묘사는 "~다")를 따른다. 조사 `이/가` 는 이름 끝 글자의 받침으로 고른다. 문구는 룰북에 아직 없다. (제안)

- 내가 북쪽으로 떠날 때 원래 방 사람들: `한백이 북쪽으로 떠난다.`(`위로`, `아래로`. 8방위는 `동쪽으로`·`북동쪽으로` 식) (제안)
- 도착한 방 사람들: `한백이 남쪽에서 다가온다.`(도착 방향은 이동 방향의 반대. `위에서`, `아래에서`) (제안)
- 접속해 세계에 들어옴: `한백이 나타난다.` 접속 끊김: `한백이 사라진다.` (제안)
- 다른 지역의 방에 들어가면 `room.zoneEntered=true` 이고 클라이언트가 방 위에 `◇ 청석숲` 한 줄을 그린다. 룰북 `◇ 지역 (권장: …)` 의 권장 경지는 1차에 없다. 접속 직후 첫 방도 `zoneEntered=true` 다. (제안)

### 캐릭터 생성 (1차 최소)

룰북 생성 절차에서 이름과 확인만 한다. 성별·외모·출신·영근은 다음 이터레이션이다. → [룰북: 캐릭터 생성](../game-rule/character.md#캐릭터-생성) (제안)

- 캐릭터가 없는 계정으로 접속하면 `session(creating)` 과 `prompt` `이름을 정하십시오. (한글 2~6자)`.
- 이름 규칙은 한글 2~6자(`^[가-힣]{2,6}$`)다. 어기면 `system/error` `이름은 띄어쓰기 없이 한글 2~6자로 정하십시오.` 뒤 같은 prompt. 이미 있으면 `system/error` `이미 있는 이름입니다. 다른 이름을 정하십시오.` 뒤 같은 prompt.
- 맞으면 `prompt` `이름 한백` 과 `이대로 만들려면 '확인', 고치려면 '뒤로'.`(두 줄). `확인` 은 만들고, `뒤로` 는 이름 prompt로 돌아가고, 그 밖은 같은 확인 prompt를 다시 보낸다.
- 만들면 `system/info` `캐릭터를 만들었습니다.`, `session(playing, 한백)`, 시작 방 `room` 을 보내고 시작 방 사람들에게 `appear` 알림을 보낸다.
- 계정당 캐릭터 1개(DB 유니크)다. 금지어·NPC 이름 검사는 NPC가 생기는 이터레이션에서 한다.
- 위 prompt·system 문구는 룰북에 아직 없다.
