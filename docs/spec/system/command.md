# 명령어 처리

플레이어가 입력하는 명령어. → [목차](index.md)

- 기존 텍스트 머드 게임의 문법을 따른다.
- 명령어별 입력 문법·출력·규칙은 [룰북: 명령어](../game-rule/commands.md)를 따른다.

## 분류

| 분류 | 예 | 룰북 |
|---|---|---|
| 대화형 명령어 | 말, 귓속말, 외치기 | [말하기 · 계정](../game-rule/commands.md#말하기--계정), [말하기와 누구](../game-rule/world.md#말하기와-누구) |
| 전투 명령어 | — | [전투](../game-rule/commands.md#전투) |
| 이동 | — | [이동 · 보기](../game-rule/commands.md#이동--보기) |
| 물건 다루기 | — | [물건](../game-rule/commands.md#물건) |
| 상인과의 거래 | — | [NPC · 상점 · 거래](../game-rule/commands.md#npc--상점--거래) |

- 위는 창호가 말한 분류다. 룰북에는 이 밖에도 정보·회복·성장·장비·제작·종문 등 분류가 있다.

### 대화형 명령어

- 플레이어끼리 말을 주고받는 명령(말, 귓속말, 외치기). [멀티 유저](platform.md#멀티-유저)에서 쓰인다.
- NPC와의 대화는 [NPC](npc.md)에서 다룬다.

## 열린 질문

- 명령어 자체(이름·줄임말·인자 형식)는 엔진 코드인가, 관리 툴에서 정의할 수 있는가? → [관리 툴](admin-tool.md)
- 웹 화면에서 명령어를 텍스트 입력으로만 받는가, 버튼·링크 같은 보조 입력도 두는가?
