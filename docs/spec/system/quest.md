# 퀘스트 · 공적 교환

→ [목차](index.md)

퀘스트 규칙(받기·진행·완료·보상·반복·포기)은 [룰북: 퀘스트](../game-rule/quest.md), 공적·교환 규칙은 [룰북: 종문 — 공적](../game-rule/game-structure.md#공적)과 [공적 교환 목록](../game-rule/game-structure.md#공적-교환-목록)을 따른다.

## 퀘스트 시스템

- 퀘스트 시스템이 있다.
- 성이나 종문에서 퀘스트를 받는다. → [룰북: 성](../game-rule/game-structure.md#성), [룰북: 종문](../game-rule/game-structure.md#종문)

## 공적 교환

- 퀘스트로 공적을 쌓고, 공적으로 필요한 공법이나 보물 같은 것을 교환한다.

## 성 · 종문별 관리 (아이디어)

> 아이디어 차원이다. 구현 목표는 추후 이터레이션에서 정한다.

- 성 또는 종문마다 퀘스트와 공적치 등을 관리한다.
- 성·종문은 관리 툴에서 먼저 정의되어야 한다. → [월드 구조](world-structure.md#성--종문-소유)

## 관리 툴

- 퀘스트와 공적 교환은 관리 툴에서 입력한다. → [관리 툴](admin-tool.md#관리-화면에서-하는-일)

## 열린 질문

- 퀘스트의 어떤 항목(목표·보상·받는 조건 등)을 관리 툴에서 입력하는가? → [관리 툴](admin-tool.md)
- 퀘스트 목표의 종류(처치·전달·수집 등)는 엔진이 정한 틀에서 고르는 방식인가?
- 퀘스트와 [이벤트 · 시나리오](event.md)는 같은 틀을 쓰는가?
