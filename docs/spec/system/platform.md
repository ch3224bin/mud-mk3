# 플랫폼

게임이 돌아가는 바탕. → [목차](index.md)

## 웹 기반

- 게임은 웹 기반이다. 플레이어는 웹에서 접속해 텍스트로 플레이한다.
- 관리 화면도 있다. → [관리 툴](admin-tool.md)
- 백엔드는 Java Spring으로 구현한다. 코딩 규칙은 [`.claude/rules`](../../../.claude/rules/README.md)에 둔다.
- 백엔드 버전(Java·Spring Boot)과 빌드 도구는 참고 레포(splearn) 기준을 따른다 — Java 21, Spring Boot 3.5.x, Gradle Kotlin DSL. 확정은 열린 질문.
- DB·통신 방식·프론트엔드 기술은 (미정).
- NPC와 내러티브는 DB로 관리한다(어떤 DB인지는 미정). → [NPC](npc.md#데이터-관리)

## 멀티 유저

- 여러 플레이어가 같은 월드에 동시에 접속해 함께 플레이한다.
- 플레이어끼리의 대화(말·귓속말·외치기)는 [명령어 처리](command.md#대화형-명령어)에서 다룬다.

## 단일 월드

- 게임은 거의 창호 또는 소수의 사람만 할 것으로 보여, 월드는 하나만 운영한다. → [월드 구조](world-structure.md)

## 열린 질문

- 백엔드 버전(Java 21, Spring Boot 3.5.x)과 빌드 도구(Gradle Kotlin DSL)를 참고 레포 기준으로 확정하는가? 루트 패키지 이름은?

- 클라이언트와 서버는 어떻게 통신하는가? (실시간 연결 방식 등) (미정)
- 계정·로그인은 어떤 방식인가? 계정 하나에 캐릭터 여럿을 둘 수 있는가? (미정) → [룰북: 캐릭터 생성](../game-rule/character.md#캐릭터-생성)
- 관리 화면은 게임 화면과 같은 웹 앱 안에 있는가, 따로인가? (미정)
