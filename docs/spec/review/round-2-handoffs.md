# Round 2 인계 — G5 명령어 장 작성자가 다른 장에 요청한 것

반영되면 [x].

- [ ] 전체: 명령 이름에는 앞부분 일치를 하지 않음(`말`/`말하기` 구분). 신통·법기·부적 이름은 명령어와 같게 짓지 않는다는 콘텐츠 규칙을 technique.md·equipment.md 콘텐츠 규칙에 한 줄씩.
- [ ] combat.md: 전투 중 `줍기` 막기(`수습`과 같게). 출력 누락: `대상` 성공, `중지` 성공·실패, `막기`·`추격` 성공·실패, `추격 중지`, `정혈 태우기`(성공·실패), 도주 시도 중 거절, 추격 중 거절. 추격 중 공격 신통·NPC 명령·수습을 막는다는 문장.
- [ ] recovery.md: `일어서기` 출력(`명상을 마칩니다.`), 수련 시간이 2시간을 넘을 때 출력, 수련실에 들어가는 명령 형태.
- [ ] realm.md: `돌파 중단` 출력. 돌파 중 `중지` = `돌파 중단`. 거절 문구(`돌파하는 중에는 할 수 없습니다. …`).
- [ ] technique.md: 본문에 `읽기 <옥간·서책·잔엽>`. `참오`·`서재 익히기`·`읽기`가 전투 중에 막히는지. `읽기 확인`·`산공 확인` 자리에 `확인`만 써도 됨. `신통` 출력 형식은 commands.md#정보 링크.
- [ ] item.md: 거래소 '보관함' → '회수함' 통일(동부 보관함과 구분). 소지품에 `(귀속)`·`(퀘스트)` 표시와 영석 등급별 표시. 출력 누락: `버리기`, 퀘스트 물건 거절, 귀속 정혈 부족, 주기·교환·거래소·경매. 전투 중 `귀속`·`교환` 막기.
- [ ] equipment.md: 출력 누락: `거두기`, `수리` 성공·실패, `본명 각인` 진행·실패, `온양`, `본명 해제`. `수리`는 괴뢰 수리와 같은 명령이라 대상 종류로 가림.
- [ ] crafting.md: `제작법` 목록 출력 형식, 전투·추격 중 `제작`·`채집` 막기.
- [ ] companion.md: `꺼내기`·`거두기`는 꺼낸 법기 → 저물대의 법기 → 괴뢰 → 영수 순서로 찾음. 출력 누락: `영수`·`계약`·`꺼내기`·`먹이기`·역할·`되살리기`·괴뢰 `수리`.
- [ ] game-structure.md: `찾기`는 동부 안이면 동부 보관함. 출력 누락: `가입`·`탈퇴`·`공적`·`동부`·보관함·`비경`·`주입`·`나가기`. 비경에 들어가는 명령(`들어가기 <입구>`와 출입 대가 확인).
- [ ] quest.md: `퀘스트 포기` 성공 출력.
- [ ] npc.md: `값` 출력.
- [ ] world.md: 출력 누락: `보기 <대상>`, `들어가기`의 없는 출구, `은신 해제`, `탐지` 의식 부족, `전송` 실패. 채팅 명령(`말하기`/`'`, `귓속말`, `외치기`)과 `누구` 의 출처 → world.md 에 '말하기와 누구' 절로 둔다(리드 결정).
- [ ] character.md: 4단계에서 `튜토리얼 건너뛰기` 거절 출력.
- [ ] party.md: `파티` 정보 명령 링크 한 줄.
- [ ] glossary(리드): 확인 대기, 회수함, 정보 명령 추가.
