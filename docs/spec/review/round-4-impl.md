# Round 4 — 구현 충분성 재검토 (impl-reviewer)

기준: 개발자가 룰북만 보고 MVP(첫 지역, 연기 1~13층 + 축기 돌파)의 게임 규칙을 빠짐없이 구현할 수 있는가. 기술 spec 은 범위 밖.
우선순위: P0 = MVP 구현 불가(핵심 루프가 막힘) / P1 = MVP에서 플레이어가 체감하는 차이가 생기는데 정해지지 않음 / P2 = 후반·사소.
제외: [decisions-needed.md](decisions-needed.md) D1~D26 때문에 비는 곳. 메시지 색·정렬처럼 구현 때 자연히 정해질 것.
대상: `git diff c664273..HEAD -- docs/spec` 의 Round 3 반영분과 game-rule 전체.

## 판정

**구현에 부족함 없음 (P0 0건, P1 0건)**

- Round 3 의 P1 3건(R1~R3)과 P2 8건(R4~R11)은 모두 해결됐다.
