# Round 0 — 구현 공백 목록 (impl-reviewer)

기준: 개발자가 룰북만 보고 게임 규칙을 빠짐없이 구현할 수 있는가. 기술 spec(DB·서버·클래스)은 범위 밖.
우선순위: P0 = MVP(첫 지역, 연기기) 구현 불가 / P1 = MVP에 있으면 좋음 / P2 = 후반(고경지·PvP·고급 콘텐츠).
항목 끝 괄호 = 담당 묶음(G1 stats·realm·technique·character / G2 combat·recovery·death·party / G3 item·crafting·equipment / G4 world·game-structure·npc·companion / G5 명령어 장).

## 명령어 장 필요 여부와 이유

- 필요하다. 룰북 전체에서 입력 형태가 정해진 명령은 `명상` 하나뿐이고, 이동·보기·신통·법기·도주·상점 등 40여 개 명령이 "명령으로 한다"고만 적혀 장마다 흩어져 있다.
- 명령마다 입력 형태(이름·별칭·인자·대상 지정), 쓸 수 있는 상태(전투 중·기절 중·명상 중·성 안), 성공·실패 출력 예시를 한곳에서 정해야 장 사이 모순(예: 명상을 끝내는 행동의 범위, 공통 대기시간에 걸리는 명령)을 막을 수 있다.
- 규칙은 각 장에 두고, `commands.md` 는 명령별 입력·출력·사용 가능 상태 표와 각 장 규칙으로 가는 링크를 둔다(G5). 상태 확인·소지품·신통 목록처럼 어느 장에도 없는 기본 명령도 여기서 정한다.

## 공통 (모든 장)

- [P0] 전 장 — 소수점 처리 규칙 없음: 위력(예: 12.0, "약 34"), 피해, 의식 회복 0.2/틱, 영력 발휘 하한 2.5 등을 내부에 소수로 들고 있는지, 언제 반올림·버림하는지, 화면에 어떻게 보여주는지 (G1)
- [P0] 전 장 — 최대치가 오를 때 현재 수치도 함께 오르는지 규칙 없음(소경지 상승·공법 단계 상승으로 육신→기혈 최대치, 의식·법력 최대치가 오를 때). 영력만 "돌파 시 현재 수치는 안 오름"이 있고 그것도 소경지 상승에 적용되는지 불명 (G1)
- [P0] 전 장 — 같은 틱에 일어나는 일의 처리 순서 없음(자연 회복·영석 회복·틱 소모·피해·기절·사망 판정 순서, 두 공격이 같은 순간 서로를 0으로 만들 때) (G2)
- [P0] 전 장 — 접속 종료 처리 없음(전투 중 접속 끊기, 명상·영석 회복 중 끊기, 꺼내 둔 영수·괴뢰·법기, 다시 접속했을 때 위치·상태). index 열린 질문 2건과 연결 (G2)

## MVP(첫 지역, 연기기) 최소 콘텐츠

룰북에 정해진 MVP 콘텐츠는 장춘공(화탄술 수치만), 연기기 비검, 연기기 방패뿐이다. 아래가 더 있어야 한 바퀴가 돈다.

- [P0] 입문 공법: 모든 영근 조합이 고를 수 있도록 오행별 또는 영근 무관 공법(단계 전체 수치 포함) (G1)
- [P0] 연기 8~13층용 수위 수단: 공법 하나 이상 또는 수위 단약 (G1·G3)
- [P0] 공격 신통 외 둔술 하나(어풍결 수치), 기혈 회복 수단 하나(단약 또는 치료 신통) (G1·G3)
- [P0] 단약: 기혈·법력 회복, 영력 회복(무리한 사용·사망 대비), 수위 단약 — 각각 값·가격 (G3)
- [P0] 몹: 1급 요수 2~3종(선공·비선공 섞어), 수습물과 영석 드롭 (G4)
- [P0] 지역: 시작 방(튜토리얼), 성 1개(상점 1~2개, 퀘스트 NPC), 사냥터 방 몇 개(영기 농도 차이) (G4)
- [P0] 퀘스트: 초반 퀘스트 몇 개(영석 보상) (G4)
- [P0] 시작 소지품: 저물대, 영석 몇 개, 비검 (G3)
- [P1] 재료·제작법 1개(연단), 부적 1개, 수련장소 1개, 영수 1종(알·새끼 판매) (G3·G4)
