# Round 2 — 구현 충분성 재검토 (impl-reviewer)

기준: 개발자가 룰북만 보고 MVP(첫 지역, 연기 1~13층 + 축기 돌파)의 게임 규칙을 빠짐없이 구현할 수 있는가. 기술 spec 은 범위 밖.
우선순위: P0 = MVP 구현 불가(핵심 루프가 막힘) / P1 = MVP에서 플레이어가 체감하는 차이가 생기는데 정해지지 않음 / P2 = 후반·사소.
제외: [round-2-handoffs.md](round-2-handoffs.md)의 명령 출력 누락(알려진 것), [decisions-needed.md](decisions-needed.md) D1~D24 때문에 비는 곳.

## 판정

**부족 (P0 3건, P1 13건)**

- Round 0 의 P0·P1 140건 가운데 136건 해결, 3건 부분, 1건 결정 대기(D9 PvP). 공식·상태 전이·처리 순서·명령어 골격은 구현 가능한 수준이다.
- 남은 P0 는 모두 **축기 돌파 직전 구간**에 몰려 있다: 연기 13층에서 공법 수위가 쌓이는지 해석이 갈리고, 축기단을 얻는 길(첫 개·실패 뒤)이 콘텐츠로 정해지지 않았다.

## 새 지적

### P0

- [x] **N1 [P0] technique.md#공법 · technique-list.md#연기-후반-공법 — 연기 13층에서 올리는 8성이 수위를 주는지 해석이 갈림 (G1)**
  - technique.md 의 정의: "'연기 7층까지' 는 단계를 올리는 순간 연기 6층 이하이면 쌓이고 7층 이상이면 쌓이지 않는다." 이 정의를 연기 후반 공법의 "수위 경지 한계 연기 13층 (돌파 수위까지)" 에 그대로 쓰면 12층 이하에서만 쌓인다. 그러면 13층에서 올리는 8성(수위 7,900)은 0 이 된다.
  - 그 경우 돌파 수위 11,000 을 단약으로만 채워야 한다. 단약 내성(50% 넘으면 10%) 때문에 약 하품 5,500어치 수위 단약이 들어 사실상 돌파할 수 없다. 반대로 technique-list 는 "2~8성이 7→8층 … 13층(돌파 수위)에 하나씩 대응" 이라 13층에서도 쌓인다고 읽힌다.
  - 권고: 수위 한계 표기를 하나로 정한다. 예: "단계마다 '수위가 쌓이는 마지막 경지' 를 적는다(입문 공법 2~7성 = 연기 6층, 연기 후반 2~8성 = 연기 13층)". technique.md 정의 문장과 경지대별 기준값 표, technique-list 두 공법 표에 같은 표기를 쓴다. 연기 13층에서 쌓인 수위가 돌파 수위를 넘어도 계속 쌓이는 것(realm 기존 규칙)도 한 줄 잇는다.
- [x G3 G4] **N2 [P0] item.md#돌파-단약 · first-region.md · game-structure.md#공적-교환-목록 — 첫 축기 돌파에 실패한 뒤 축기단을 다시 얻는 MVP 경로가 없음 (G4·G3)**
  - 성공률은 보통 36~68%(예시 48%)라 절반쯤은 첫 시도에 실패한다. 실패하면 단약만 잃는다(창호 규칙). 그런데 나머지 공급원이 첫 지역에 콘텐츠로 없다.
  - 종문 공적: 황엽곡의 가입 조건·종문 퀘스트·교환 목록이 없다. 일반 예("축기단 400, 누적 공적 1,000, 한 달 1개")만 있다.
  - 연단: 축기단 단방이 없다. 비경: 적안 금지는 "축기단 재료" 라고만 되어 있고 무엇이 얼마나 나오는지 없다. 경매: 공급자가 없다.
  - 권고: 첫 지역에서 두 번째 축기단을 얻는 길을 하나 이상 콘텐츠로 정한다.
    - 황엽곡: 가입 조건, 종문 반복 퀘스트 2~3개(공적 보상), 공적 교환 목록(축기단 포함)
    - 또는 축기단 단방(난이도·재료·도구)과, 적안 금지의 축기단 재료 보상표
- [x] **N3 [P0] character.md#초반-흐름 · first-region.md#남원성 — 핵심 경로의 일회 퀘스트 셋의 내용이 없음 (G4)**
  - 비검을 주는 튜토리얼 첫 퀘스트, 연기 후반 공법을 주는 연기 7층 퀘스트, 축기단을 "반드시" 주는 연기 13층 퀘스트. 셋 다 MVP 루프가 기대는 확정 공급원인데 주는 NPC·받는 조건·종류·목표·완료 NPC·보상이 없다.
  - 특히 "연기 13층 무렵" 이 받는 조건인지 모호하다(13층 도달? 수위 몇 이상?).
  - 권고: quest.md 의 '퀘스트가 가지는 것' 항목대로 세 퀘스트를 first-region 에 표로 둔다. character.md 의 `> 미정` 은 지운다.

### P1

- [x] **N4 [P1] realm.md#돌파-진행 — 돌파 중에 내 뜻과 상관없이 생기는 일의 처리가 없음 (G1)**
  - 수련실 이용 시간이 0이 되어 밖으로 내보내질 때, 비경 제한 시간이 끝날 때가 그렇다. 돌파 중에는 이동할 수 없는데 끊기는지·이어지는지가 없다.
  - 꺼낸 영수·괴뢰나 은신의 의식 소모로 돌파 중 기절할 때도 없다. 돌파 중에는 `거두기` 를 쓸 수 없다.
  - 권고: 위 경우를 '돌파가 끊기는 때' 에 넣을지 정한다. 또는 돌파 조건에 "꺼낸 영수·괴뢰가 없고 은신 중이 아님" 을 더한다. 수련실·비경 시간은 돌파 중 멈추게 해도 된다.
- [x] **N5 [P1] realm.md#성공률 ↔ item.md#돌파-단약 — 돌파 단약 품질 보정이 성공률 식에 없음 (G1)**
  - item 은 "중계 +2%p · 상계 +4%p · 정계 +6%p" 인데, realm 의 성공률 식과 `돌파` 출력에는 이 항이 없다.
  - 권고: 식에 '단약 품질 보정' 항을 더한다. 단약을 여러 품질로 가졌을 때 어느 것을 쓰는지(가장 높은 것 / `돌파 시작` 인자로 고름)도 정한다.
- [x] **N6 [P1] technique-list.md#연기-후반-공법 — 연기 후반 공법을 어디서 무엇을 얻는지 덜 정해짐 (G1·G4)**
  - 서방이 6종(오행 5 + 철골공) 모두를 500에 파는지 모른다.
  - 연기 7층 퀘스트의 "자기 영근에 맞는 것 하나" 에 철골공이 드는지 모른다. 강체결만 수련한 캐릭터가 받을 수 있어야 한다.
  - 권고: 서방 판매 목록과 퀘스트 선택지를 공법 이름으로 적는다.
- [x] **N7 [P1] combat.md#몹과-파티원의-행동 — 몹 둔술이 재사용 대기 중일 때 막기를 할 수 있는지 (G2)**
  - 지금 규칙대로면 몹의 막기에도 둔술 재사용 대기(10초)가 걸린다. 그래서 둔술 없이 도주하다 실패해도 5초 뒤 다시 도주하면, 몹 둔술이 아직 대기 중이라 항상 성공한다. "항상 막기로 대응" 과 맞지 않는다.
  - 권고: 몹의 막기는 둔술 재사용 대기를 무시하는지, 대기 중이면 대응하지 못하는지 정한다. 플레이어가 막을 때와 같은지도 함께 정한다.
- [x G3·G2] **N8 [P1] combat.md#추격 · item.md#부적-콘텐츠-규칙 — 둔술 부적의 추격 유지와 이동력 (G2·G3)**
  - 추격 중에는 "판정 때 쓴 둔술을 틱마다 법력 20% 로 유지" 한다. 그런데 둔술 부적은 법력을 쓰지 않는다. 그러면 무한히 유지되는지, 추격 시작 때 풀리는지 모른다.
  - 경신부의 "연기 10층 기준 둔술과 같은 이동력" 은 배율이 없다(1.3~2.0 범위만 있음).
  - 권고: 부적 둔술의 추격 중 지속(예: 부적에 지속 시간 10초)을 정하고, 경신부 배율을 수로 적는다.
- [x] **N9 [P1] combat.md#처리-순서 — 지속 피해(독) 규칙이 없음 (G2·G4)**
  - 처리 순서에 '지속 피해' 자리가 있고, 요수 신통에 '독' 이 있으며, 첫 지역에 적안 독사가 있다. 그런데 독의 양·지속·중첩·끝나는 때·육신 층 적용 여부가 없다.
  - 권고: 지속 피해 규칙을 정하거나, 첫 지역 몹은 독을 쓰지 않는다고 적는다.
- [x G2 G4] **N10 [P1] npc.md#적대-수선자 — 도주에 성공한 적대 수선자의 그 뒤 (G4·G2)**
  - 산적 수선자(흑풍곡 주력 몹, 퀘스트 '산적 소탕' 대상)는 기혈 25% 아래에서 도주한다. 성공한 뒤 어디에 있는지가 없다(이웃 방에 남아 다시 공격받는지, 세계에서 사라지는지).
  - 플레이어가 추격을 골랐을 때 몹 도주자가 어떻게 옮겨 다니는지, 도주한 몹이 퀘스트 처치 수에 드는지도 없다.
  - 권고: "도주에 성공하면 이웃 방에 나타났다가 N초 뒤 사라진다 / 바로 사라진다" 처럼 정하고, 몹 도주자의 추격 중 이동(가장 먼 출구로 2초마다 등)을 정한다.
- [x G2 G4] **N11 [P1] npc.md#선공과-배회 — 선공 대상과 첫 공격 시점 (G4)**
  - 같은 방에 플레이어가 여럿이거나 영수·괴뢰가 꺼내져 있을 때 선공 몹이 누구를 노리는지가 없다. 사람마다 선공 대기를 따로 세는지도 없다.
  - 선공 대기 3초 끝의 공격이 '첫 행동' 인지, 그 뒤 1.5초를 더 기다리는지(combat '교전이 시작되면 1.5초 뒤 첫 행동')도 없다.
  - 권고: 대상 규칙(예: 선공 대기를 먼저 시작한 플레이어. 영수·괴뢰는 선공하지 않음)과 시점을 한 줄씩 적는다.

- [x] **N14 [P1] quest.md#진행 — 보상으로 받은 물건이 '퀘스트 물건' 인지 (G4)**

- [x] **N15 [P1] death.md#떨어뜨리는-소지품 ↔ game-structure.md#비경-탐사 — 혼자 들어가는 비경에서 떨어뜨린 유품을 되찾을 수 없음 (G2·G4)**
  - 혼자 비경은 들어갈 때마다 새로 열리고, 재입장 간격은 게임 하루(현실 4시간)다. 그런데 유품은 30분 뒤 사라진다. 그래서 "다시 들어가 주워야 한다" 가 성립하지 않는다.
  - 비경 안에서 부활하면 같은 인스턴스라 주울 수 있지만, 시간이 다 되어 나온 뒤에는 되찾을 길이 없다.
  - 권고: 비경 안 유품은 나올 때 함께 나오게 하거나(입구 방), 유품 주인의 재입장은 간격 예외로 하거나, 되찾을 수 없음을 규칙으로 명시한다.
- [x G2 G4] **N16 [P1] game-structure.md#비경-탐사 — 비경 안에서 접속 종료 (G4·G2)**

  - 권고: 수련실 규칙(안에서 끊으면 안에서 시작, 시간은 멈춤)처럼 한 단락으로 정한다.

### 명령어 연결 (G5)

- 장에 있는 명령은 모두 commands.md 표에 있다. commands 에만 있고 장 규칙이 없는 것은 `!`·`도움말`·`누구`·`귓속말`·`외치기` 다. 채팅·`누구` 는 round-2-handoffs(world.md '말하기와 누구' 절)와 index 열린 질문에 이미 있다.
