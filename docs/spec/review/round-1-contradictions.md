# Round 1 모순 검토

Round 1 작성자들이 병렬로 쓴 뒤 나온 장 간 모순. 통합(reconcile) 단계에서 하나로 맞춘다. 원칙: 창호가 쓴 원래 문장이 이긴다. 둘 다 (제안)이면 design-baseline 에 가까운 쪽, 그다음 더 단순한 쪽을 택한다. 반영되면 [x].
