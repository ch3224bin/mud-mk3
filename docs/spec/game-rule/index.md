## 열린 질문

- 특수 체질(영근과 별개로 타고나는 몸의 특성)을 게임에서 쓸 것인가, 쓴다면 어느 분류인가?
- 다른 플레이어에게 죽었을 때 떨어뜨리는 소지품과 줍는 권한은? (몹·NPC에게 죽었을 때는 정함. PvP 허용 여부에 걸림 → [decisions-needed D9](../review/decisions-needed.md)) → [사망 페널티](death.md#사망-페널티)
- 진법(원작의 취령진 등)이나 동부로 장소의 영기 농도를 바꿀 수 있게 할 것인가? (지금은 장소마다 고정) → [영기 농도](recovery.md#영기-농도)
- 종족을 어떻게 정의할 것인가? (원작에는 인족·요족·충족·각치족·영족 등 많은 종족이 있다. 예: 요수가 화형하면 요족이 되고, 보물이 오래되면 영족이 된다. 추후에 정의하기로 함) → [화형](companion.md#영수), [몹](npc.md#몹)
- 낮·밤에 따라 달라지는 것(귀물이 밤에 강해지는 것 등)을 둘 것인가? (지금은 표시만) → [게임 시간](world.md#게임-시간)
- 채팅 범위(외치기를 지역으로 할지, 서버 전체 채널을 둘지)와 `누구` 에 경지를 보여 줄지? → [명령어](commands.md)
