## 열린 질문

- 특수 체질(영근과 별개로 타고나는 몸의 특성)을 게임에서 쓸 것인가, 쓴다면 어느 분류인가?
- 사망할 때 떨어뜨리는 소지품의 범위는? (전부·일부·저물대 통째로, 꺼내 둔 법기 포함 여부, 죽인 상대가 NPC인지 플레이어인지에 따라 다른지) → [사망 페널티](death.md#사망-페널티)
- 상점에서 결제할 때 하품이 모자라면 높은 등급(예: 극품)이 플레이어 확인 없이 깨져 거슬러지는가? 거스름 하품이 저물대 칸을 넘치면 어떻게 되는가? → [영석](item.md#영석)
- 상점이 물건을 사 주는 데 한도나 감가가 있는가? (재료 구매 → 즉시 제작 → 되팔기 반복으로 영석을 무한히 벌 수 있는지) → [영석](item.md#영석), [제작](crafting.md#제작)
- 영약을 원작처럼 영초(연단 재료)로 볼 것인가, 법력을 즉시 회복하는 별도의 약으로 둘 것인가? (원작의 灵药은 주로 영초를 가리킴) → [법력](stats.md#법력)
- '연체술사'를 어떤 조건으로 판정하는가? (연체술은 공법 계열 이름이라, 영구를 쓸 수 있는 사람의 기준이 없음) → [부리기](equipment.md#부리기)
- 접속한 채 명상을 켜 두고 기다리는 플레이(방치 명상)를 의도한 플레이로 받아들이는가? (오프라인 회복 없음, 기혈 자연 회복 없음, 돌파 전 풀 컨디션 필요, 정혈 자연 회복은 매우 느림) → [회복과 휴식](recovery.md#회복과-휴식)
- 상대가 접속을 끊거나 장소를 떠나거나 오래 교전이 없을 때 전투 상태는 어떻게 끝나는가? (전투 중에는 명상을 할 수 없어 기혈 회복이 막힐 수 있음) → [진행 방식](combat.md#진행-방식)
- 수련장소의 보호는 전투 상태인 사람에게도 적용되는가? (전투 중 수련장소에 들어가면 도주 판정이 필요한지, 진법·신식 공격도 막는지) → [수련장소](recovery.md#수련장소)
- '접속을 끊은 동안 회복 없음'이 진행 중인 영석 회복, 경지 안정 기간·사망 후의 영력 차오름에도 적용되는가? → [회복과 휴식](recovery.md#회복과-휴식)
- 진법(원작의 취령진 등)이나 동부로 장소의 영기 농도를 바꿀 수 있게 할 것인가? (지금은 장소마다 고정) → [영기 농도](recovery.md#영기-농도)
- 종족을 어떻게 정의할 것인가? (원작에는 인족·요족·충족·각치족·영족 등 많은 종족이 있다. 예: 요수가 화형하면 요족이 되고, 보물이 오래되면 영족이 된다. 추후에 정의하기로 함) → [화형](companion.md#영수), [몹](npc.md#몹)
