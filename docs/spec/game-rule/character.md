# 캐릭터 생성과 초반 흐름

← [룰북 목차](index.md) · 용어의 뜻은 [용어집](../glossary.md) 참고.

## 캐릭터 생성

- 캐릭터를 만들 때 다음을 정한다.
  - **이름**: 캐릭터 이름(도호 등)
  - **성별·외모**: 텍스트로 보여줄 성별과 간단한 외모 묘사
  - **출신**: 출신(지역·집안 등)을 고른다. 출신에 따라 시작 지역이나 튜토리얼이 달라진다. 그 외에는 영향이 없다(능력치 차이 없음).
  - **영근**: 오행 중 1~5개를 고른다. → [영근 · 영근 자질](stats.md#영근--영근-자질)
  > 미정: 출신 목록, 출신별로 달라지는 시작 지역·튜토리얼

## 입문

- 새 캐릭터는 범인(영력 0)으로 시작한다. 입문 과정을 거쳐 연기 1층이 된다. → [영력 (진원)](stats.md#영력-진원), [경지](realm.md#경지)
- 입문 과정은 튜토리얼 이벤트다. 시작 지역에서 게임 조작을 배우는 짧은 이벤트다.
- 기본 공법은 튜토리얼 이벤트 안에서 몇 가지 기본 공법(입문 공법) 중 고른다. 고른 입문 공법을 읽으면 바로 1성에 이르고, 입문 공법의 1성에 이르면 연기 1층이 된다. → [공법](technique.md#공법)
  > 미정: 튜토리얼 이벤트의 내용, 시작 지역, 고를 수 있는 기본 공법 목록

## 초반 흐름

- 튜토리얼을 마친 뒤에는 시작 지역 근처 성의 초반 퀘스트가 이어진다. 이 퀘스트들이 자연스럽게 종문·성·비경을 소개한다. → [게임 구성](game-structure.md#게임-구성)
  > 미정: 초반 퀘스트의 내용과 보상, 초반 퀘스트가 끝나는 시점
