# 경지

← [룰북 목차](index.md) · 용어의 뜻은 [용어집](../glossary.md) 참고.

- 대경지는 다음 13개이며, 이 순서로 오른다.

  연기 → 축기 → 결단 → 원영 → 화신 → 연허 → 합체 → 대승 → 진선 → 금선 → 태을 → 대라 → 도조

- 대경지 안은 소경지로 나뉜다.
  - 연기: 1층 ~ 13층
  - 축기부터: 초기 → 중기 → 후기 → 대원만
- 수위는 단약 또는 공법 수련으로 쌓는다.
  - **단약**: 수위를 올리는 단약을 먹는다.
  - **공법 수련**: 수위를 쌓아 주는 공법의 단계가 오를 때 수위가 쌓인다. 모든 공법이 수위를 주지는 않고, 공법마다 수위를 주는지가 정해져 있다. → [공법](technique.md#공법)
  > 미정: 단약·공법 단계 상승으로 쌓이는 수위의 양, 소경지 하나를 오르는 데 필요한 수위
- 소경지 상승: 낮은 대경지에서는 수위가 차면 소경지가 자동으로 오른다. 어느 대경지부터는 소경지를 돌파하는 데도 조건이 필요하다.
  > 미정: 소경지 돌파에 조건이 필요해지는 대경지, 그 조건
- 대경지 상승: 플레이어가 돌파 시도를 해야 오른다. 돌파 방법은 경지마다 다를 수 있다.
  - 경지 돌파 수위에 도달해야 돌파를 시도할 수 있다.
  - 풀 컨디션이어야 돌파를 시도할 수 있다. 풀 컨디션은 영력(진원) 현재 수치, 법력, 기혈, 의식, 정혈이 모두 최대치인 상태다. 그래서 돌파 직후 영력이 안정되기 전에는 다음 돌파를 시도할 수 없다. → [영력 (진원)](stats.md#영력-진원)
  - 돌파 시도에는 단약을 소모한다.
  - 보물은 돌파 확률을 높여주는 보조 수단이다. 돌파에 성공했을 때만 소모된다.
  - 돌파는 실패할 수 있다. 성공률은 영근 자질에 따라 달라진다. → [영근 · 영근 자질](stats.md#영근--영근-자질)
  - 영근이 여러 개면 가장 높은 영근 자질을 기준으로 한다.
  - 돌파는 어디서나 시도할 수 있지만, 주변 영기 농도가 높을수록 성공률이 오른다.
  - 돌파에 실패하면 단약만 소모된다. 수위는 줄어들지 않는다.
  - 돌파 진행 방식(검토 중인 방향): 멀티 유저 게임 특성상 즉시 결과가 나와야 할 것 같지만, 소설처럼 시간에 따라 이벤트가 발생하면 더 좋다. 대경지 돌파는 캐릭터가 겪을 수 있는 몇 안 되는 이벤트이므로, 임팩트 있게 진행하면 재미있을 것이다.
    > 미정: 돌파 시도에 걸리는 시간, 진행 중 발생하는 이벤트, 플레이어에게 보여주는 연출
  > 미정: 경지별 돌파 수위, 경지별 돌파 방법과 필요한 단약, 성공률 계산 방식, 보물이 높여주는 확률
- 경지에 따라 오르는 스탯(기혈, 법력, 육신, 근력 등)은 소경지가 오를 때마다 오른다. 대경지를 돌파할 때는 소경지 상승보다 훨씬 크게 오른다.
  > 미정: 소경지·대경지별 스탯 상승량

> 미정: 경지 스펙을 정할 때 함께 다룰 원작 용어 — 선원력(선계 경지에서 법력 대체), 원신/원영, 심마/도심. → [용어집 > 미분류](../glossary.md#미분류-게임에서-쓸지-미정)

> 미정: 수원(남은 수명)을 넣을지. 넣으면 좋을 것 같지만, 멀티 유저 게임 특성상 다루기가 어려워 우선 미정으로 둔다.
