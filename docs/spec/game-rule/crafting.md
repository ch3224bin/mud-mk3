# 제작

← [룰북 목차](index.md) · 용어의 뜻은 [용어집](../glossary.md) 참고.

- 제작에는 다음 다섯 가지가 있다.
  - **법기 제련**: 재료로 법기를 만든다. → [법기](equipment.md#법기)
  - **연단**: 재료로 단약을 만든다.
  - **부적 제작**: 부적(보부 포함)을 만든다. → [부적](item.md#부적)
  - **진법원반 제작**: 진법원반을 만든다. → [진법원반](item.md#진법원반)
  - **괴뢰 제작**: 재료로 괴뢰를 만든다. → [괴뢰](companion.md#괴뢰)
- 제작하려면 **제작법**(단방·제련법 등)과 재료, 그리고 **제작 도구**(단로 등)가 필요하다. 도구의 등급이 결과에 영향을 준다. 정해진 장소는 필요 없다.
  > 미정: 제작 종류별 도구, 도구 등급과 그 영향, 도구를 얻는 방법
- 제작법은 다음 방법으로 얻는다.
  - **옥간·서책**: 제작법이 담긴 옥간·서책을 읽어 배운다.
  - **구매**: 성 상점이나 종문(공적)에서 산다. → [종문](game-structure.md#종문), [성](game-structure.md#성)
  - **비경·기연**: 비경·유적이나 기연으로 희귀한 제작법을 얻는다. → [비경 탐사](game-structure.md#비경-탐사)
- 제작은 즉시 이루어진다. 대신 제작에는 재사용 대기시간(쿨타임)이 있다.
  > 미정: 재사용 대기시간의 길이, 제작 종류별로 따로인지, 제작에 스탯(법력 등)을 소모하는지
- 제작할수록 제작 종류별로 **제작 숙련도**가 쌓이고, 숙련도가 높을수록 더 좋은 것을 만든다. 숙련도가 높을수록 성공률이 오르고, 높은 품질이 나오기 쉽다. (법기 고유 신통의 숙련도와는 별개 → [고유 신통과 숙련도](equipment.md#고유-신통과-숙련도))
- 재료는 다음 방법으로 얻는다.
  - **채집**: 장소에서 영초·광석 등을 채집한다.
  - **요수 처치**: 요수를 쓰러뜨려 요단·가죽·뼈 등을 얻는다.
  - **구매**: 성 상점이나 종문에서 산다. → [종문](game-structure.md#종문), [성](game-structure.md#성)
  - **비경·탐험**: 비경이나 동부·유적에서 희귀한 재료를 얻는다. → [비경 탐사](game-structure.md#비경-탐사)
  > 미정: 재료 종류, 채집 방법과 채집할 수 있는 장소
- 제작은 실패할 수 있다. 성공하면 결과물의 품질이 달라진다. (법기의 품질 → [등급](equipment.md#등급))
- 제작에 실패하면 넣은 재료를 모두 잃는다. 실패해도 제작 숙련도는 쌓인다.
  > 미정: 숙련도에 따른 성공률·품질 상승 정도, 숙련도가 오르는 양, 성공률과 품질을 정하는 요소, 단약·부적·진법원반의 품질이 무엇을 바꾸는지
