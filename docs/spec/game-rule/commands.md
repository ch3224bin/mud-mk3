# 명령어

← [룰북 목차](index.md) · 용어의 뜻은 [용어집](../glossary.md) 참고.

명령의 입력 형태와 결과를 한곳에 모은다. 규칙 자체는 각 장에 있고, 이 장은 링크한다. 규칙·명령 형태·출력의 원본은 각 장이다. 이 장과 장이 다르면 장을 따르고 이 장을 고친다. 장에 없고 이 장에만 있는 출력은 † 로 표시한다. (제안)

## 공통 규칙

### 입력 문법

- 명령은 `명령어 인자1 인자2 …` 처럼 명령어를 먼저, 인자를 뒤에 띄어 쓴다. 띄어쓰기가 여럿이어도 하나로 본다. (제안)
- 인자 순서는 명령마다 정한 대로다: 보통 `명령 대상`, `명령 대상 물건 [수량]`, `명령 물건 [수량]`. `[ ]` 는 빼도 되는 인자, `< >` 는 꼭 적는 인자다. (제안)
- 이름에 띄어쓰기가 있어도 그대로 쓴다(`팔기 청모랑 가죽 3`). 마지막 낱말이 수이면 수량으로 본다. 수량 자리에 `전부` 를 쓰면 가진 것 모두다(`팔기 늑대 가죽 전부`). (제안)
- 명령어는 정해진 이름과 줄임말로만 알아듣는다. 명령어 앞부분만 쓰는 것(예: `말` 로 `말하기`)은 받지 않는다. 앞부분 일치는 대상·물건 이름에만 쓴다. (제안)
- 신통·법기 고유 신통은 그 이름이 곧 명령어다(`화탄술 늑대`, `비검 늑대`). 신통 이름이 다른 명령어와 같으면 명령어가 먼저다. 그래서 신통·법기 이름은 명령어와 겹치지 않게 짓는다. (제안) → [대상 지정](combat.md#대상-지정)
- `!` 는 바로 앞에 쓴 명령을 다시 쓴다. (제안)

### 대상 지정

- 대상(사람·몹·시체·바닥의 물건·NPC)은 같은 방에 있는 것 가운데서, 물건은 내 소지품에서 찾는다. 명령마다 어디서 찾는지가 정해져 있다(표의 '하는 일'). (제안)
- 이름이 맞는 때: 이름 전체, 이름의 앞부분, 이름을 이루는 낱말 하나의 앞부분. 그래서 `회춘단` 은 `회춘단(연기 초)` 를, `수습 청모랑` 은 `청모랑의 시체` 를, `가죽` 은 `늑대 가죽` 을 가리킨다. (제안)
- 맞는 것이 여럿이면 방 보기(소지품은 소지품 목록)에 보이는 순서로 첫째다. 둘째부터는 `2.늑대` 처럼 번호를 붙인다. 묶여 보이는 몹(`청모랑 (1급) ×3`)도 번호로 하나씩 가리킨다. (제안) → [방 보기](world.md#방-보기)
- 전투 중 공격 신통의 대상을 빼면 현재 대상에게 쓴다. `대상 이름` 으로 바꾼다. → [대상 지정](combat.md#대상-지정)
- 숨어 있어 보이지 않는 대상은 이름으로 가리킬 수 없다(없는 것처럼 나온다). 부활 보호 중인 대상은 가리킬 수 있지만 공격 명령은 거절된다(전투 장 문구). → [숨기](world.md#숨기), [안전 장소](combat.md#안전-장소), [부활](death.md#부활) (제안)

### 공통 오류 메시지

모든 명령에 같은 문구를 쓴다. 명령마다 따로 정한 메시지가 있으면 그것이 먼저다. 조사(은/는, 을/를, 이/가)는 앞 낱말 받침에 맞춰 바꾼다. (제안)

| 경우 | 메시지 |
|---|---|
| 알 수 없는 명령 | `무슨 말인지 모르겠습니다. ('도움말' 로 명령을 볼 수 있습니다)` † (제안) |
| 인자 부족 | `누구에게 쓰시겠습니까? (예: 화탄술 늑대)` (전투 장 문구) / 물건이면 `무엇을 주우시겠습니까? (예: 줍기 늑대 가죽)` † 처럼 동사와 예를 바꾼다 (제안) |
| 방에 대상 없음 | `이곳에 '곰'은 없습니다.` (전투 장 문구) |
| 소지품에 물건 없음 | `그런 물건은 가지고 있지 않습니다.` (아이템 장 문구) |
| 수량이 잘못됨 | `수량은 1 이상의 수로 적으십시오.` † (제안) / `늑대 이빨은 2개뿐입니다.` (아이템 장 문구) |
| 대상이 맞지 않음 | `늑대에게는 그렇게 할 수 없습니다.` † (예: 시체가 아닌 것에 `수습`) (제안) |
| 이 방에서 못 씀 | `이곳에서는 할 수 없습니다.` † (예: 상점 주인이 없는 방에서 `사기`) (제안) |

### 공통 대기시간

공통 대기시간은 1.5초다. → [진행 방식](combat.md#진행-방식)

| 걸린다 (공통 대기시간 중에는 못 쓰고, 쓰면 공통 대기시간이 생김) | 걸리지 않는다 (공통 대기시간 중에도 쓰고, 써도 생기지 않음) |
|---|---|
| 모든 신통(법기 고유 신통·둔술 포함), `부적`(공격·방어), 법기 `꺼내기`, `진법`(펼치기) | `영석`, `복용`, `대상`, 법기 `거두기`, 영수·괴뢰 `꺼내기`·`거두기`, `탐지`(자체 재사용 10초), `수습`, `줍기`, `버리기`, `도주`·`막기`·`추격`(둔술 없이), `정혈 태우기`, `중지`, `추격 중지`, 정보 명령, 말하기 |

- 둔술(둔술 부적 포함)을 붙인 `도주`·`막기`·`추격` 은 공통 대기시간 중에도 쓸 수 있지만, 쓴 순간 공통 대기시간과 둔술 재사용 대기시간이 걸린다. → [도주 판정](combat.md#도주-판정)
- 공통 대기시간이 0.3초 이하 남았을 때 들어온 신통 명령 하나는 예약된다. → [대기시간 중 입력](combat.md#대기시간-중-입력)
- 거절 문구: `아직 기운을 고르는 중입니다. (0.6초)` (공통 대기시간) / `화탄술은 아직 쓸 수 없습니다. (1.8초)` (재사용 대기시간). 전투 장 문구다.

### 출력 문체

- 시스템 안내(결과·거절·수치)는 "~습니다/~십시오" 로 쓴다: `회색늑대를 따돌렸습니다.` (제안)
- 묘사(일어나는 일·몸의 느낌)는 "~다" 로 쓴다: `가부좌를 틀고 앉아 천지의 영기를 받아들인다.` 한 줄에 묘사와 결과가 함께 있으면 묘사를 먼저, 결과를 뒤에 쓴다: `회색늑대가 길을 막지 못한다. 북쪽으로 달아났습니다.` (제안)
- NPC 말은 `이름: "…"` 또는 `이름이 … 말한다. "…"` 로 쓰고, NPC 말투(하오체 등)는 NPC마다 정한다. (제안)
- 수치는 괄호 안에 둔다: `(기혈 +30, 42/60)`, `(14초)`, `(하품 영석 -15)`. 남은 시간은 60초 미만이면 소수 첫째 자리까지 초, 그 이상은 `3분`·`7분 12초` 로 쓴다. (제안) → [소수점](stats.md#소수점)

정보 명령 출력 형식 (연기 3층, 목·화 진영근, 장춘공 3성 예) (제안)

```
> 상태
한백 · 남 · 연기 3층 · 목·화 진영근 (목 52, 화 50)
기혈  80 / 80     법력  39 / 39
의식  25 / 25     정혈  24 / 24
육신  8   근력  4   영력  7 / 7
수위  310 / 420   (이번 층 단약 수위 40 / 210)
깨달음  금 0 · 목 131 · 수 0 · 화 230 · 토 0 · 연체 0
영기: 보통   영석 회복 중 (6초)   금강부 (24초)
[전투 중] 상대: 회색늑대(기혈 많이 상함), 회색늑대 2
```

- 줄 순서: 이름·경지·영근 → 소모 스탯 → 포인트 스탯 → 수위 → 깨달음 → 이곳 영기·지속 효과 → 전투 줄. 값이 없는 줄(전투 중이 아님, 지속 효과 없음)은 빼고, 아래 상황 줄은 해당할 때만 붙인다. (제안)
  - 경지 안정 중: 영력 줄을 `영력  21 / 34   (경지 안정 중, 남은 7분 12초)` 로 바꾼다(스탯 장 형식). → [영력 (진원)](stats.md#영력-진원)
  - 돌파 수위를 넘겼으면 `수위 11,420 / 11,000 (돌파 가능)`. → [수위](stats.md#수위)
  - 정혈이 깎여 최대치가 줄었으면 최대치 뒤에 `(정혈로 -12)` 처럼 줄어든 몫을 붙인다. 기절·보호·추격·명상·지속 피해 중이면 맨 끝에 `[기절 4초]` `[보호 중 42초]` `[추격당하는 중]` `[명상 중]` `[중독 3초]` 를 붙인다. `[중독 3초]` 는 전투 장 문구다. → [지속 피해](combat.md#지속-피해)
- 단약 수위 줄의 210 은 이번 소경지에 단약 내성 없이 받는 몫이다(필요 수위의 50%). → [단약으로 쌓이는 수위](realm.md#단약으로-쌓이는-수위)

```
> 소지품
[소지품 8/22칸]  하품 영석 132 · 중품 영석 1
중계 비검 (꺼냄, 귀속)   하계 방패 (내구도 24/24)
회춘단(연기 초) x5   회기단(연기 초) x3
늑대 가죽 x12   늑대 이빨 x4   왕씨의 약초 꾸러미 (퀘스트)
```

- 아이템 장의 출력 형식이다. 영석은 가진 등급만 첫 줄에 붙이고(`하품 영석 132 · 중품 영석 1`), 귀속 물건 뒤에 `(귀속)`, 퀘스트 물건 뒤에 `(퀘스트)`, 꺼낸 법기 뒤에 `(꺼냄)`, 방어 법기 뒤에 내구도, 파괴된 법기 뒤에 `(파괴)` 를 붙인다. → [저물대 · 저물탁](item.md#저물대--저물탁)

```
> 신통
[장춘공 3성]
  화탄술   공격·화   법력 5    대기 3초
  천안술   탐지·목   법력 3    대기 10초   (4.2초 남음)
  어풍결   둔술·목   법력 10   대기 10초
[법기 · 꺼낸 것]
  비검     공격      법력 없음  대기 3초    중계 비검 · 숙련 2단계
```

- 공법마다 묶고, 꺼낸 법기의 고유 신통을 뒤에 둔다. 재사용 대기시간이 남은 것만 남은 시간을 붙인다. 시전 시간이 있는 신통은 `시전 2초` 를 대기 앞에 붙인다. 법기 이름과 고유 신통 이름이 다르면 둘 다 쓸 수 있는 명령으로 보인다(`진벽 (방패)`). (제안)

```
> 공법
장춘공   3/9성 · 목 · 오행   다음 4성: 목 깨달음 280 (지금 131)
강체결   1/9성 · 연체        다음 2성: 연체 깨달음 450 (지금 0)
(서재에 익히지 않은 공법 1개 — '서재')
```

- 끝까지 오른 공법은 `9/9성 · 끝에 이름`, 경지가 모자라면 `(연기 7층 필요)` 를 붙인다. 자질 조건은 `참오` 에서 자세히 본다. (제안)

## 이름 겹침 정리

같은 낱말이 여러 뜻으로 쓰이거나 장마다 이름이 다른 것. 이 장의 선택을 따른다. (제안)

| 겹침 | 정리 |
|---|---|
| 단약 먹기: `먹기` ↔ `복용` | `복용` 하나. `먹기` 는 쓰지 않는다(영수에게는 `먹이기`) |
| `찾기`: 거래소·경매장 회수 ↔ 동부 보관함 | 있는 곳으로 가린다. 동부 안이면 동부 보관함, 거래소·경매장 NPC 방이면 회수함. 이름도 거래소 쪽은 '회수함', 동부 쪽은 '보관함' 으로 나눈다 |
| `꺼내기`·`거두기`: 법기 ↔ 영수 ↔ 괴뢰 | 한 명령, 찾는 순서로 가린다([영수 · 괴뢰](#영수--괴뢰)). 공통 대기시간은 법기 꺼내기만 |
| `수리`: 법기(상점·직접) ↔ 괴뢰 | 한 명령, 대상 종류로 가린다. 괴뢰만 `[영석 수]` 를 받는다. 법기는 법기점 방이면 상점 수리, 그 밖이면 직접 수리이고, 법기점 방에서 직접 고치려면 `수리 <법기> 직접` |
| `목록`: 상점 ↔ 공적 교환 ↔ `퀘스트 목록` ↔ `거래소 목록` | `목록` 만 쓰면 이 방 상점·공적 교환. 나머지는 앞에 붙는 낱말로 가린다 |
| `확인`: 결제·탈퇴·생성·포기·비경 출입·동부·`본명 해제` ↔ `읽기 확인`·`산공 확인` ↔ `교환 확인` | 확인 대기는 `확인` 하나로 받고 앞 두 형태도 받는다. `교환 확인` 은 별개 |
| 끊기: `중지`(시전) ↔ `추격 중지` ↔ `돌파 중단` ↔ `일어서기`(명상) | 그대로 둔다. 돌파 중에 `중지` 를 쓰면 `돌파 중단` 과 같게 받는다 |
| `말` (NPC 말 걸기) ↔ `말하기` (채팅) | 둘 다 둔다. 명령어 앞부분 일치를 받지 않으므로 헷갈리지 않는다 |
| `영수` (목록) ↔ `영수 <이름> 탐지` ↔ `탐지` | `영수` 뒤에 이름이 있으면 역할 명령이다 |
| `동부` (관리 NPC 명령) ↔ 이름 있는 출구 `동부` | 출구는 `들어가기 동부`, 명령 `동부` 는 관리 NPC 방에서만 |
| 신통 이름 ↔ 명령어 | 명령어가 먼저다. 신통·법기·부적 이름은 이 장 명령어와 같게 짓지 않는다 |
